Quizzness - COMP1170 school prototype

Open the root index.html in Chrome or Firefox. The website uses local HTML,
CSS, JavaScript and image files. It needs no account, installation, internet
connection, development server, or build step.

Pages (nine root HTML files):
- index.html: investor-facing Quizzness concept, audience and sample worlds
- experience.html: Mathematics lesson, two percentages minigames, demo XP,
  progress, reset, and a fictional friends leaderboard
- tutoring.html: fictional tutor request, tutor application preview, and
  illustrative pending and approved GiveBack hours
- feasibility.html: product, market, operational risks and pilot evaluation
- business-model.html: proposed revenue, operating costs and pricing gaps
- industry.html: target audience, competitors, launch, marketing and measures
- team.html: venture purpose, group members and references
- sources.html: references, artwork credits and aggregate survey evidence
- signup.html: optional, unlinked signup-form preview; no account is created

In the learning demonstration, select Mathematics, read the lesson, match
percentage runes with fractions, then order bridge stones by calculated
amount. Correct completion awards 50 sample XP per minigame. The leaderboard
uses fictional friends and updates only for this visit. Reset or refresh
restores the starting example.

The tutoring page lets you review and confirm a fictional sample request.
Its separate application form can preview a name, subjects, CV and
recommendation selections. No request or application is sent, saved or
uploaded. Use sample details and documents rather than personal records.
The GiveBack Wallet shows fixed illustrative records; recognition would
require a formal university agreement.

Survey evidence: the group's 28-response survey is summarised on
sources.html. Its recruitment method and response verification still need
documentation. The figures are exploratory responses, not proof of demand,
pilot results or learning improvement.

Known limitations: only the Mathematics world has working activities;
Programming and other topics are previews. There is no backend, database,
authentication, real signup, booking, file upload or persistent progress.
The school prototype is separate from quizzness-game/.
