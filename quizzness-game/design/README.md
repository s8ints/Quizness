## Typography (dashboard refresh, 2026-10-08)

Font roles, inspired by how Codédex assigns fonts by job (no Codédex fonts, art or wording copied). All are free OFL fonts bundled locally via Fontsource:
- Silkscreen 700: wordmark and page titles (`--font-logo`).
- Pixelify Sans: section titles, buttons, room spots, Panthy's name (`--font-display`).
- Silkscreen 400 uppercase, spaced: eyebrows, card labels, pills (`--font-label`). Avoid "&" in these labels; the glyph reads like "$".
- Nunito: nav, body text, speech, forms (`--font-body`).
Minimum text size is 12px. Rules live in src/styles/refresh.css, loaded last. Still the user's choice, not an extracted original brand font.

## Student walking sprites (2026-10-09)

Generated by `scripts/make-student-sprites.cjs` from the original `public/brand/student-characters.png`; only existing pixels are moved (no redraw, recolour or blur). Output in `public/sprites/students/` with `students.json` (frame size 64×136, frame order, fps, notes). Review at `/sprites/students/preview.html` on the dev server.

- Native size: 57×128 character in a 64×136 frame (≈1/6 of the source), nearest-neighbour downscale, hard alpha, light edge halo removed. Draw at whole-number scales with pixelated rendering.
- Walk: 8 frames per cycle with leg lift and inward tuck, torso dip and sway toward the planted foot, smooth hip lean, and head/hair trailing the body by one frame. Idle: 2-frame slow breathing.
- Shadows are separate layers (`shadow-day`, faint `shadow-night`) sized to each character's feet.
- Front view only. `walk-left`/`walk-right` lean the front view toward travel and `walk-up` reuses `walk-down`: **stopgaps** until side/back views are drawn. Books' legs touch, so they are split on the dark seam.
- Day/night rules are not yet decided.
