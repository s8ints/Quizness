Quizzness

Quizzness Over Pleasure

Our idea is a website where university students can practise course topics through games and get help from peer tutors when they get stuck.

Try the sample activity

The problem

Following an explanation in class and answering a question on your own are different things. We want to help students practise between classes and find someone to explain topics they are struggling with.

Study groups and WhatsApp chats can be useful, but our idea puts practice, feedback and peer support in one place. We still need interviews to find out how common these problems are and whether students would use Quizzness.

Who would use it?

  • Students: practise coursework and ask for help with specific topics.
  • Peer tutors: help other students and record eligible GiveBack time.
  • Universities and colleges: provide access and oversee course content and tutoring.

How it would work

  1. Read the course material.
  2. Try a game or practice question.
  3. Check the feedback.
  4. Practise the weak topic or ask a peer tutor for help.
  5. Try again.

Sample courses

  • Programming: Code Kingdom. Try our binary search tree question.
  • Mathematics: Puzzle Temple. A planned second course, with no activity built yet.

This prototype shows one practice question and a tutoring example. It does not create accounts, save scores or book sessions.

Our proposal

We would start with Programming and Mathematics at one university. The main question is whether linking course practice to peer help gives students a reason to use the website regularly.
