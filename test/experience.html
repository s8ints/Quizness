Variables and addition

A variable is a name that stores a value. The + symbol adds two numbers together. You have 2 apples and buy 3 more.


        apples = 2
        more_apples = 3
        total = apples + more_apples

What value will total have?

Choose an answer by opening its explanation.

5 apples

Correct! Add the values: 2 + 3 = 5. The value stored in total is 5.

Finish the sample and review your next step →

2 apples

Try again. 2 is the number you started with. The total also includes the 3 new apples.

3 apples

Try again. 3 is only the number of new apples. Add the 2 apples you already had.

Static sample: answers expand using HTML. Attempts are not recorded and no score is calculated.

After the sample

If you answered correctly, try another addition question with different values. If you were unsure, replace each variable with its number before calculating.

In the proposed product, a completion screen would show topics answered correctly and topics to revisit. We would test learning with separate application questions, rather than treating a game score as proof of understanding.
