Code Kingdom: programming practice

This is a sample of how a course activity could work. Read the explanation, try a question and use the feedback to decide what to practise next.

Binary search trees

In a binary search tree, smaller values go in the left subtree and larger values go in the right subtree. To insert a value, start at the root and compare it with each node until you reach an empty position.

For this example, the root is 50. Its left child is 30 and its right child is 70.

Course topics

We would organise the course into small activities. These are our planned areas for Code Kingdom:

  1. Variable Woods: values and types
  2. Logic Ruins: conditions
  3. Loop Gate: iteration
  4. Tree Garden: binary search trees (sample below)
  5. Function Mountain: functions
  6. Final challenge: questions from different topics

Practice question

Where should 20 go in this tree?

    50
   /  \
  30  70

Click an answer to read its explanation.

As the left child of 30

Correct. 20 is smaller than 50, so go left to 30. It is also smaller than 30, so it becomes the left child of 30.

View the sample progress report

As the right child of 30

Try again. A right child would need to be larger than 30, but 20 is smaller.

As the left child of 70

Start at 50. Since 20 is smaller than 50, it belongs in the left subtree. You should go through 30 rather than 70.

Adding more activities

We plan to use question and game templates. A lecturer or approved creator would add course material, and a coordinator would check the questions and explanations before students use them.

The full service would need accounts and progress tracking. Those features are not part of this website yet.
