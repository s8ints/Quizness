LEARN COURSEWORK / SAMPLE MATERIAL

Start with the concept.

In a binary search tree, values smaller than a node go in its left subtree and larger values go in its right subtree. To insert a value, compare it with each node as you follow the branches to an empty position.

Example: to insert 20 below root 50, move left because 20 is smaller. At node 30, move left again. The activity below lets you inspect the feedback for each possible placement.

Plant 20 as the right child of 30
Try another placement. 20 is smaller than 30. A right child would need to be larger than its parent. Return to the choices and follow the left branch.
Plant 20 as the left child of 70
Start at the root. Although 20 is smaller than 70, it is also smaller than 50. It belongs in 50’s left subtree, so continue through 30.

BEHIND THE EXPERIENCE

Built from approved course material.

A lecturer or approved creator selects a game template, enters the problem and explanation, and sends it for course review. Automatic AI game generation is not part of the proposed MVP.

Choose a mechanic

Use a puzzle, path choice or debugging mission that fits the learning goal. Small questions sit inside a course adventure.

Review before release

The course coordinator checks correctness, permitted source material and explanations before a quest is published.

Connect the feedback

Each activity maps to a topic. A weak-topic suggestion opens relevant peer support and then returns the learner to practice.
