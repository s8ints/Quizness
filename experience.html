2. Percent Path: learn the idea

Mathematics / Puzzle Temple

A percentage means “per hundred.” To find 20% of an amount, write 20/100 = 0.20 and multiply the amount by 0.20.

A worked example

What is 20% of BBD 40?

  1. Convert the percentage: 20 ÷ 100 = 0.20.
  2. Multiply: 0.20 × 40 = 8.
  3. The answer is BBD 8.

For 25%, use 25/100 = 0.25. This is the same as one quarter, so you can also divide the amount by 4.

Useful equivalents: 20% = 1/5, 25% = 1/4, and 50% = 1/2.

Learning source: OpenStax (2020), Prealgebra 2e, Section 6.1. See the source details.

    Beyond this sample

    We would organise each course into small activities. These are our planned areas for Puzzle Temple:

    1. Percent Path: percentages (working sample)
    2. Fraction Falls: fractions (preview)
    3. Ratio Bridge: ratios and proportion (preview)
    4. Equation Tower: solving equations (preview)
    5. Final challenge: questions from different topics (preview)

    We plan to use question and game templates. A lecturer or approved creator would add course material, and a coordinator would check the questions and explanations before students use them.

    Like Duolingo's repeated practice model, Quizzness uses short interactive challenges to reinforce learning. Unlike Quizlet, Quizzness connects weak topics directly to peer tutoring.

    This prototype uses HTML, external CSS, and introductory JavaScript. It does not save progress, assess a whole course, or book tutoring sessions.
