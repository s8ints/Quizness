Code Kingdom: programming practice

This is a sample of how a course activity could work. Read the explanation, try a question and use the feedback to decide what to practise next.

Variables and addition

A variable is a name that stores a value. You can use those values in a calculation. The + symbol adds two numbers together.

For this example, you have 2 apples and buy 3 more. Add the two numbers to find the total.

Try the question below

Course topics

We would organise the course into small activities. These are our planned areas for Code Kingdom:

  1. Variable Woods: values and types (sample below)
  2. Logic Ruins: conditions
  3. Loop Gate: iteration
  4. Tree Garden: binary search trees
  5. Function Mountain: functions
  6. Final challenge: questions from different topics

Practice question

What value will total have?

apples = 2
        more_apples = 3
        total = apples + more_apples

Click an answer to read its explanation.

5 apples

Correct. Replace the variable names with their values: 2 + 3 = 5. The value of total is 5.
