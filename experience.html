THE CONTRIBUTION LOOP

Useful questions need accountable review.

Proposed network interaction: learner → question contribution → peer tutor review → published question → learner feedback.

Draft with context

A contributor adds a question, topic, explanation, and permitted reference. Drafts stay out of practice sessions until reviewed.

Review before publication

A peer tutor checks correctness and clarity. Proposed question cards show review status and revision history.

Improve after practice

A learner flags an unclear answer. The question returns to review; accepted corrections improve future sessions.

The cards above describe proposed states. This website demonstrates the interface only; it does not store contributions.
